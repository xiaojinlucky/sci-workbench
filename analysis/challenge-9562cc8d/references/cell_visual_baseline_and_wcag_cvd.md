# Cell 视觉基线、色彩语义与 WCAG-CVD 规范

本规范定义本 Skill 的发表级视觉默认参数，确保单栏/通栏缩放、色觉障碍读者阅读与黑白打印场景均保持高可读性。

## 1. Cell 倾向物理画布与排版基线

| 规范项 | 默认标准 | 执行要求与理由 |
| --- | --- | --- |
| 物理栏宽 | 单栏 `85 mm`、1.5 栏 `114 mm`、双栏 `174 mm` | 从最终发表物理尺寸作图，禁止大画布作图后暴力缩小导致字号失真 |
| 纵横比 | 内容驱动自然长宽比（默认高宽比约 `0.72`） | 不强制方形画布；依据组数、标签长度与图型（热图/长轨迹）调整 |
| 字体家族 | `Arial`, `DejaVu Sans`, `Liberation Sans` | 无衬线统一清晰；导出 PDF 设 `pdf.fonttype=42`（TrueType 嵌入），SVG 设 `svg.fonttype="none"`（保留可编辑文本） |
| 字号范围 | `7–12 pt`（默认基准 `8 pt`，主标题 `9 pt`，刻度 `7.5–8 pt`） | 低于 `7 pt` 在单栏印刷中难以辨认；汇报场景须按实际图片框折算可读字号 |
| 标题对齐 | 所属 panel 数据绘图区水平居中，常规字重（`loc="center"`, `fontweight="normal"`） | 排除纵轴标签与右侧图例占位偏移，简洁英文短语概括对象与比较 |
| 边框与网格 | 隐藏顶部与右侧脊线（`top/right spines`），默认不加背景网格线 | 提升数据-墨水比，避免网格线与原始散点/误差棒竞争注意力 |
| 图例布局 | 默认单行紧凑布局，与完整坐标轴装饰保持 `2–6 pt` 净距 | 禁止图例侵入数据区或与横轴标题重叠 |
| 导出边界模式 | `bbox_inches=None`（固定物理画布） | 严禁使用 `bbox_inches="tight"` 悄悄裁切改变物理宽度与相对字号 |
| 位图与矢量导出 | 矢量 `SVG` / `PDF` 优先；位图 `PNG` 固定 `300 dpi` RGB | 保证印刷级线条锐度与审稿预览清晰度 |

## 2. 色彩语义角色与已验证色板

不同数据类型必须严格匹配色彩语义角色，不得混用：

1. **分类定性（`qualitative`）** — 无序分组、实验处理臂、物种/品种：
   - 默认色板（经 WCAG/CVD 校验全 8 色任意配对在 Protanopia/Deuteranopia/Tritanopia 下 $\Delta E_{76} > 16$）：`#0072B2`（深蓝）、`#D55E00`（朱红）、`#009E73`（蓝绿）、`#CC79A7`（紫红）、`#E69F00`（琥珀）、`#56B4E9`（天蓝）、`#332288`（靛蓝）、`#882255`（酒红）。
   - 同一项目的类别-颜色映射固定后跨图沿用，不因对话偏好对单个对象做无规则高亮。
2. **连续单调（`sequential`）** — 浓度、丰度、绝对强度：
   - 默认色板：`#F2F7FA → #C8DFEC → #8DBBD6 → #4E8FB9 → #266294 → #12395D`。
   - 要求相对亮度严格单调递减，确保灰度打印后大小顺序不翻转。
3. **零中心发散（`diverging`）** — 相关系数 `[-1, 1]`、变化量（log2FC、delta）：
   - 默认色板：`#1F4E79 → #5B8DB8 → #B9D2E6 → #F7F7F7 → #F2C0A2 → #DC7643 → #9E3614`。
   - 明确声明中点（如 `0`），两端亮度对称下降以便区分正负方向与强度。

## 3. WCAG 2.1、色觉障碍（CVD）与灰度硬检验指标

`palette_cvd_auditor.py` 使用纯 Python 3.12 标准库执行三项定量检验：

1. **WCAG 2.1 对比度**：基于 sRGB 线性化计算相对亮度 $L = 0.2126 R_{\text{lin}} + 0.7152 G_{\text{lin}} + 0.0722 B_{\text{lin}}$ 与对比度 $(L_{\text{hi}} + 0.05)/(L_{\text{lo}} + 0.05)$；线条/散点相对白底推荐 $\ge 3.0$，带深色描边柱体 $\ge 2.0$，热图文字自动选取更高对比度的 `#111827` 或 `#FFFFFF`。
2. **CVD 线性 RGB 模拟**：对每对分类色应用 Viénot/Machado 矩阵模拟 **Protanopia（红盲）**、**Deuteranopia（绿盲）** 与 **Tritanopia（蓝黄盲）**，并转换至 CIELAB 计算欧氏色差 $\Delta E_{76}$；正常视觉 $\Delta E < 15$ 或红绿色盲 $\Delta E < 9$ 直接判 FAIL 阻断。
3. **禁用彩虹色标**：硬阻断 `jet`、`rainbow`、`hsv`、`gist_rainbow`、`nipy_spectral`、`turbo`（其在青/黄波段存在亮度尖峰，导致定量数据出现虚假阶跃与色盲失效）。
