# Reconciliation Protocol, Domain Presentation & Scope Boundaries

## 1. Independent Disk Read-Back Reconciliation (`quality_reconciler.py`)

A data quality report generated by free-form LLM prose frequently disagrees with the actual cleaned CSV. Every run MUST pass six deterministic disk read-back checks:
1. **Byte-level SHA-256 match**: Re-hash `<stem>.csv` from disk and verify exact match with `manifest.output_csv_sha256`.
2. **Row conservation identity**: `rows_raw == rows_cleaned_disk + rows_dropped_consistent_duplicates + rows_quarantined_conflicts_disk`.
3. **Leading-zero-preserving primary-key uniqueness**: Re-read primary-key columns strictly as strings and confirm `len(unique_pks) == rows_cleaned_disk`.
4. **Value-state distribution identity**: Re-tally `Counter(row["value_state"])` from disk and assert exact equality with `manifest.cell_accounting.value_state_counts`.
5. **Field-level completeness**: Compute `non_empty_rows`, `empty_or_null_rows`, `missing_rate_pct`, `exact_zero_rows`, and `has_raw_backup_column` directly from disk rows.
6. **Zero-imputation attestation**: Verify `manifest.imputation_performed is False`.

Any discrepancy yields a non-zero exit code from `quality_reconciler.py` and blocks sealing `result.json` as `"ok"`.

## 2. Domain-Readable Output vs Internal Implementation State

- Reports (`*_quality.md`) and `result.json` findings must use domain-clear data stewardship terminology (e.g., "Below limit of detection", "Conflicting primary-key duplicates quarantined", "Physical QC range alert"), never raw script debugging jargon.
- Keep technical audit details (SHA-256 hashes, raw line numbers, regex flags, conversion logs) cleanly organized in `*_manifest.json`, `*_reconciliation.json`, and `reproduce_*.py`.
- Always distinguish verified cleaned rows, quarantined conflicts requiring human decision, and unresolved unit/format faults.

## 3. Scope Boundaries

- **In Scope**: Encoding/delimiter repair, leading-zero ID preservation, five-way missing/sentinel vs true-zero classification, duplicate identification and conflict quarantine, per-metric reversible unit normalization, physical QC bound flagging, disk-reconciled quality reports, and linear reproduction scripts.
- **Out of Scope**: Statistical hypothesis testing/modeling, publication figure styling, database server administration/RBAC, experimental design, and manuscript writing.
