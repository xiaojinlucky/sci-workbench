# 科研示意图图形语法与布局规范

1. **关系语法对齐**
   - 因果/激活：`causal`/`activate` 使用实线箭头（`->`）。
   - 抑制/阻断：`inhibit` 使用垂直平头 T-bar（`-|`）。
   - 平行/协同：`parallel` 使用虚线圆端连线。
   - 反馈回路：`feedback` 使用虚线回流箭头。
2. **层级与包含关系**
   - 父子所属或实验阶段组用 `containers` 框体包围子节点，不在外框中混写并列关系。
3. **数据表与图例一致性**
   - 使用 `--data-table` 绑定 CSV/TSV/JSON 时，每个绑定节点的 `data-value` 与填充色必须对应图例条目与源表字段。
