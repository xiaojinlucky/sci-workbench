# 复合 SI 量纲代数与数量级核验表

## 1. 7 维 SI 基准量纲向量
所有物理与化学单位均投影到 7 维 SI 基准指数向量 `(L, M, T, I, Theta, N, J)` 及相对于基准 SI（`m, kg, s, A, K, mol, cd`）的精确缩放因子 `si_scale_factor`：

| 轴 | 物理量 | SI 基准单位 | 备注 |
| --- | --- | --- | --- |
| `L` | 长度 | `m` | `1 cm = 1e-2 m`, `1 Å = 1e-10 m`, `1 L = 1e-3 m^3` |
| `M` | 质量 | `kg` | 内部 `g` 缩放为 `1e-3`，从而 `kg = 1.0`, `mg = 1e-6`, `Da = 1.660539e-27 kg` |
| `T` | 时间 | `s` | `min = 60`, `h = 3600`, `d = 86400` |
| `I` | 电流 | `A` | `mA = 1e-3 A` |
| `Theta` | 热力学温度 | `K` | 绝对温标或温差 |
| `N` | 物质的量 | `mol` | 摩尔浓度 `M = mol/L = 1e3 mol/m^3` |
| `J` | 发光强度 | `cd` | `lm`, `lx` |

## 2. 通用复合单位语法（递归下降解析）
`math_ast_guard.parse_unit_expression()` 支持任意复合表达式，不再受限于写死词表：
- **乘法**：`*`、`·`、`⋅`、`\cdot` 或空格隐式相乘（如 `m s^-2`、`kg m^2 s^-3 A^-1`）。
- **除法**：`/`（左结合，支持括号分组如 `kg*m^2/(s^3*A)`、`J/(mol*K)`、`mA/cm^2`、`mg/L`）。
- **指数**：`^n`、`^-n`、`^{n}`、`^(n/m)`、`**n` 与 Unicode 上标 `²`、`³`、`⁻¹`、`⁻²`。
- **SI 前缀自动拆分**：支持 `Y/Z/E/P/T/G/M/k/h/da/d/c/m/u/µ/μ/n/p/f/a/z/y`，并避免把 `mol`、`min`、`bar` 等非前缀单位误拆。

## 3. 典型复合科研单位对照示例
| 表达式 | 7 维向量 `(L,M,T,I,Theta,N,J)` | 相对基准 SI 缩放因子 | 常见数量级陷阱 |
| --- | --- | --- | --- |
| `m/s^2` / `m s^-2` | `[1, 0, -2, 0, 0, 0, 0]` | `1.0` | 加速度基准 |
| `kg*m^2/(s^3*A)` | `[2, 1, -3, -1, 0, 0, 0]` | `1.0` | 等价于伏特 `V` |
| `J/(mol*K)` | `[2, 1, -2, 0, -1, -1, 0]` | `1.0` | 气体常数 `R` 与摩尔熵 |
| `kJ/mol` | `[2, 1, -2, 0, 0, -1, 0]` | `1e3` | 与 `J/mol` 量纲一致但差 `10^3`（`log10_gap = +3.0`） |
| `mA/cm^2` | `[-2, 0, 0, 1, 0, 0, 0]` | `10.0` | 与 `A/m^2` 量纲一致但差 `10^1`（电化学高频错位） |
| `mg/L` | `[-3, 1, 0, 0, 0, 0, 0]` | `1e-3` | 等价于 `g/m^3`，与 `kg/m^3` 差 `10^-3` |
| `eV` | `[2, 1, -2, 0, 0, 0, 0]` | `1.602176634e-19` | 与 `J` 量纲一致但差 `~10^-18.8` |
| `Pa*s` | `[-1, 1, -1, 0, 0, 0, 0]` | `1.0` | 动力黏度，等价于 `kg/(m*s)` |

## 4. 双层核验判定规则
1. **量纲一致性（`consistent`）**：左右两侧 7 维向量逐轴差值全为 0；若任意轴非零，记 `DIMENSIONAL_MISMATCH` 并给出 `dimension_delta`。
2. **数量级缩放偏移（`scale_exact_match` / `order_of_magnitude_gap`）**：当量纲一致但 `scale_ratio != 1.0` 时（例如左边 `kJ/mol`、右边用 `R*T` 的 `J/mol`），显式触发 `UNIT_ORDER_OF_MAGNITUDE_OFFSET`，拦截静默差 `10^3` 或 `10^1` 的经典代入错误。
