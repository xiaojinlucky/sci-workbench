# Third-Party Notices

This skill package contains original offline Python 3.12 standard-library scripts and Markdown documentation authored for scientific figure and table parsing (`challenge-f35e4ca5`).

## Optional Preinstalled Runtime Dependencies (Not Bundled)

- **Pillow (`PIL`)** — optional image luminance/cropping diagnostics; core PNG/JPEG/BMP/GIF/TIFF header inspection runs in pure Python stdlib when Pillow is absent.
- **defusedxml** — optional hardened XML parser for SVG figures; falls back to stdlib `xml.etree.ElementTree`.
- **Poppler (`pdftotext`) / pdfplumber / pypdf** — optional PDF text extraction when a PDF accompanies the figure case.

Zero AGPL/LGPL digitization code or prohibited PDF/SVG/COM libraries are bundled or imported.
