# 复合单位 / 区域数字 / 温差换算字典

## 1. 区域数字（Locale）判别规则 (`R02`)

支持通过 `case.json` 指定 `number_locale`（`auto` / `en` / `eu`），默认 `auto` 按以下确定性规则判别并记录变更日志：

| 原始写法示例 | `auto` 判别逻辑 | 解析结果 | 审计记录 |
|---|---|---|---|
| `1,25`、`0,085`、`-3,4` | 单个逗号且逗号后非 3 位数字（1、2 或 ≥4 位） | 欧式小数：`1.25`、`0.085`、`-3.4` | `R02_EU_DECIMAL_COMMA` |
| `1.250,5`、`12.345,67` | 同时含 `.` 与 `,` 且 `,` 在 `.` 之后 | 欧式千分点+小数逗号：`1250.5`、`12345.67` | `R02_EU_THOUSANDS_DECIMAL` |
| `1,250.5`、`12,345.67` | 同时含 `,` 与 `.` 且 `.` 在 `,` 之后 | 英美千分逗号+小数点：`1250.5`、`12345.67` | `R02_EN_THOUSANDS_DECIMAL` |
| `1,250`（单逗号后恰 3 位，无小数点） | `en` 或 `auto` 按千分位 `1250` 解析；`eu` 按小数 `1.25` 解析；在 `auto` 模式下同时写入 `ambiguous_locale_comma` 复核提示 | `1250`（`auto`）+ 复核提示 | `R02_AMBIGUOUS_COMMA_NOTICE` |
| `1.2×10^-3`、`1.2e-3`、`1,5×10^4` | 支持 `e/E` 与 `×10^` / `x10^` 科学计数法 | `0.0012`、`15000.0` | `R02_SCIENTIFIC_NOTATION` |
| `<0.05`、`<= 0.05`、`>100`、`LOD < 0.02` | 保留 `censor_operator`（`<`/`<=`/`>`/`>=`），仅对数值部分换算单位 | `value_kind="censored"`, `censor_operator="<"`, `normalized_value=...` | `R02_CENSORED_DETECTION_LIMIT` |

## 2. 常用复合单位与 SI 换算表 (`R03`)

- **电位**：`V`（基准）、`mV` (`x * 1e-3`)、`uV`/`µV` (`x * 1e-6`)、`kV` (`x * 1e3`)
- **电流**：`A`（基准）、`mA` (`x * 1e-3`)、`uA`/`µA` (`x * 1e-6`)、`nA` (`x * 1e-9`)
- **电流密度**：`mA/cm^2`（基准，兼容 `mA/cm2`、`mA cm-2`）、`A/cm^2` (`x * 1000`)、`uA/cm^2` (`x * 1e-3`)、`A/m^2` (`x * 0.1`)
- **质量**：`g`（基准）、`kg` (`x * 1e3`)、`mg` (`x * 1e-3`)、`ug`/`µg` (`x * 1e-6`)、`ng` (`x * 1e-9`)
- **质量浓度**：`mg/L`（基准，等价 `ug/mL`/`µg/mL`）、`g/L` (`x * 1000`)、`ug/L`/`µg/L` (`x * 1e-3`)、`ng/mL` (`x * 1e-3`)；`ppm`（基准）、`ppb` (`x * 1e-3`)
- **摩尔浓度**（区分大小写 `M` vs `m`）：`mol/L`（基准，等价 `M`）、`mM`/`mmol/L` (`x * 1e-3`)、`uM`/`µM`/`umol/L` (`x * 1e-6`)、`nM` (`x * 1e-9`)、`pM` (`x * 1e-12`)
- **温度与温差（ΔT 强制守卫）**：
  - 绝对温度：`K`（基准）、`°C`/`degC`/`C` (`x + 273.15`)、`°F`/`degF` (`(x - 32) * 5/9 + 273.15`)
  - **温差 / 误差棒**：`Δ°C`/`delta_C`/`ΔC`/`degC_diff` 或 `±` 不确定度 → **`K` (`x * 1`，绝不加 `273.15`)**；`Δ°F` → `K` (`x * 5/9`)
- **时间**：`s`（基准）、`ms` (`x * 1e-3`)、`us`/`µs` (`x * 1e-6`)、`min` (`x * 60`)、`h`/`hr`/`hours` (`x * 3600`)、`d`/`day`/`days` (`x * 86400`)
- **能量**：`J`（基准）、`kJ` (`x * 1e3`)、`MJ` (`x * 1e6`)；`eV`（基准）、`meV` (`x * 1e-3`)；`kJ/mol`（基准）、`J/mol` (`x * 1e-3`)、`kcal/mol` (`x * 4.184`)
- **长度 / 面积 / 体积 / 压力 / 速率**：
  - 长度：`m`（基准）、`cm` (`1e-2`)、`mm` (`1e-3`)、`um`/`µm` (`1e-6`)、`nm` (`1e-9`)、`Å` (`1e-10`)
  - 面积与比表面积：`m^2`（基准）、`cm^2` (`1e-4`)、`mm^2` (`1e-6`)；`m^2/g`（基准）
  - 体积：`L`（基准）、`mL` (`1e-3`)、`uL`/`µL` (`1e-6`)
  - 压力：`Pa`（基准）、`kPa` (`1e3`)、`MPa` (`1e6`)、`GPa` (`1e9`)、`bar` (`1e5`)、`atm` (`101325`)
  - 催化/流体速率：`mmol/g/h`（基准，兼容 `mmol g-1 h-1`）、`umol/g/h`/`µmol/g/h` (`1e-3`)、`mol/g/h` (`1e3`)；`mL/min`（基准）、`L/h` (`1000/60`)
  - 比例：`%`（基准，兼容 `pct`/`percent`）、`wt%`、`at%`、`vol%`

## 3. 有效数字保留 (`precision_sigfigs`)

从原始数字字符串提取有效数字位数（去除前导零与科学计数法指数部分，保留小数末尾有效零，如 `0.0850` 记 `3` 位有效数字、`12.40` 记 `4` 位有效数字），避免浮点换算掩盖原始测量精度。
