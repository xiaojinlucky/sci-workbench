# Third-Party Notices (challenge-16d4414d)

This Skill package runs solely on the Python 3.10+ standard library with optional runtime detection of preinstalled document parsers (`pdfplumber`, `pypdf`, `python-docx`, `pdftotext`). No banned or copyleft third-party libraries are bundled.

- ACL Rolling Review (ARR) Reviewer Guidelines (H1-H17 fairness checklist, public documentation).
- Defect-first five-gate admissibility and evidence-chain audit principles (original implementation in this package).
