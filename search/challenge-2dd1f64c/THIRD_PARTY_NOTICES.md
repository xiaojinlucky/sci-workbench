# Third-Party Notices

Implemented exclusively with the Python 3.12 standard library. No third-party source code is bundled.

## Optional Runtime Backends (Not Bundled)

If present in the container, optional PDF extraction may use `pdfplumber` (MIT), `pypdf` (BSD-3-Clause), or Poppler `pdftotext` CLI; otherwise the Skill runs cleanly in metadata-only mode and reports the limitation explicitly.

## Methodology References (Concepts Only; No Code Copied)

- Traceable duplicate-ignoring concepts informed by systematic-review screening practices (preserving duplicate identity and provenance rather than silent deletion).
- PRISMA flow count conservation and Cohen's kappa inter-signal agreement formulas follow standard literature-screening conventions.
