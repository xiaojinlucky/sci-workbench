# 学术论文结构分层、三向对齐与体例决策规范

## 一、Results 与 Discussion 分列 vs 合并的裁决矩阵

针对研究者高频困惑（分开写易重复、合并写易冲淡主线），按以下优先级裁决，**绝不凭经验替作者瞎猜目标期刊体例**：

| 输入条件 | 结构动作 | 段落级硬约束 |
| --- | --- | --- |
| 目标期刊/任务明确要求 **分列** | 使用独立 `# Results` 与 `# Discussion` 章节 | Results 仅报观测事实（对象、比较组、数值、单位、统计量、图号），**零机制推测**；Discussion 不逐条照抄 Results 全量数字，聚焦科学含义、文献异同、带标注的机制假说与局限。 |
| 目标期刊/任务明确要求 **合并** | 使用 `# Results and Discussion` | 每个子节内严格分层：**前半段客观观测句（锚定表图与统计量） → 后半段解释与文献对照句（明确使用 `suggests`/`may reflect` 等限定词）**，末尾仍保留独立 Limitations 段。 |
| 目标期刊体例 **未规定（`UNSPECIFIED`）** | 默认采用清晰分列，并在 `change_log` 与 `gaps` 显式标 `journal_structure_spec: UNSPECIFIED` | 保留作者切换合并/分列的自由度，提供段落级合并/拆分指引，绝不伪造期刊格式要求。 |

## 二、三向对齐核验协议（材料 ↔ 正文与图注 ↔ 参考文献）

1. **材料索引先行**：动笔前运行 `manuscript_workbench_engine.py index` 扫描 `/input` 全部实验表、记录、图注与 `.bib`/`.json`，把每条材料映射到目标章节。
2. **数值与条件绑定**：正文与摘要中的每个数值、单位、样本量（`n`）、误差定义（`SD`/`SEM`/`95% CI`）、`p`/`FDR` 值必须可回溯至具体 `file:line` 或 `file:row:col`。
3. **摘要与正文一致性**：摘要中出现的全部核心数值与样本量必须在正文 Results/Methods 中完全一致，严禁摘要写一套、正文写另一套。
4. **参考文献双层校验**：
   - 第一层（存在性）：正文 `[n]` / `\cite{}` 与文末 References 1:1 匹配，零悬空引用、零未引用孤立条目、零编造 DOI；
   - 第二层（支持性）：逐条核对所引文献的实际结论与适用范围是否支撑所在句，避免装饰性引用与强因果越界。

## 三、章节完备性与必备学术声明清单

标准实证研究论文须覆盖：
1. `Abstract`（四拍结构：问题 → 缺口 → 方法 → 核心定量结果）
2. `Introduction`（研究脉络、明确缺口、本文方案与贡献，禁空洞开场）
3. `Methods`（样本/数据、实验步骤、参数、统计方法与版本，缺项标 `[EVIDENCE_GAP: ...]`）
4. `Results`（按主线问题与图序组织，保留阴性/未显著结果）
5. `Discussion`（核心回答、文献对照、局限性与未来方向）
6. `References`（统一格式，字段齐备）
7. **声明字段**：`Data and Code Availability`、`Ethics Statement`（若涉及人类/动物）、`Competing Interests`；输入未提供时显式标注 `[EVIDENCE_GAP: ...]` 供作者填写，严禁编造审批号或公开仓库链接。

## 四、缩写与术语一致性规则

- 除通用标准缩写（如 `DNA`、`RNA`、`PCR`、`SD`、`SEM`、`CI`、`FDR`、`DOI`）外，首次在摘要和正文出现时分别给出全称与括号缩写，如 `vascular endothelial growth factor (VEGF)`；
- 全篇保持单一拼写、大小写、连字符与中文规范译名一致。
