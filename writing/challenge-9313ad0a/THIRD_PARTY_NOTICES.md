# Third-Party Notices

This Skill package contains original pure-Python standard library code and Markdown reference documentation for offline scientific mind map authoring and verification.

At runtime, the script optionally invokes preinstalled container tools when present:
- `fc-list` (Fontconfig) for CJK font discovery
- `rsvg-convert` (librsvg) or `matplotlib` for PNG preview rendering

No third-party binaries, fonts, or external Python packages are bundled in this Skill.
