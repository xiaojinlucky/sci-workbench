# Output Contract Specification and Pre-Seal QA (`bilingual-academic-translation`)

## 1. Required Deliverables Under `/app/output/`

1. `/app/output/result.json` — Structured final record containing all 5 original `output_contract` fields plus runtime status and provenance.
2. `/app/output/translated.md` — Editable full target-language manuscript maintaining structural parity with the source document.
3. `/app/output/bilingual_aligned.md` — Paragraph-by-paragraph editable bilingual parallel alignment generated by `scripts/bilingual_alignment_guard.py --out-aligned` with per-paragraph verification badges.
4. `/app/output/translation_audit.json` — Complete deterministic verification ledger generated by `scripts/bilingual_alignment_guard.py --out-json`.

## 2. Exact 5-Field `result.json` Schema

Merge `/app/work/contract_patch.json` (generated by `bilingual_alignment_guard.py --out-contract-patch`) into `/app/output/result.json` via `result_guard.py --finalize`:

## 3. Pre-Seal Verification Gate

Before finishing, verify every box:
- `bilingual_alignment_guard.py` returned exit code `0` (`"passed": true`).
- Zero unattested numeric order swaps, zero magnitude/unit errors, zero dangling/mismatched citations, zero reference DOI/year/title swaps, zero negation polarity flips, and zero causal overclaim escalations.
- Every `metrics` key in `result.json` has a matching entry in `metric_provenance`.
- `gap_gate.py` and `final_audit.py` exit `0` with zero ungrounded DOIs or raw placeholder markers.
