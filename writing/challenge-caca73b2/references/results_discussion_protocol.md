# 结果与讨论写作协议（条件行绑定、阴性保留与 CNS 讨论四拍）

## 一、Results（结果段）：客观观测与条件行 1:1 绑定

1. **只陈述观测事实，零机制推测**：每段按“测试的科学子问题 → 比较条件与样本量 → 定量方向/幅度/误差定义/精确统计量 → 图/表编号”展开。
2. **条件行精准绑定（严防张冠李戴）**：写下某组（如 `Low-dose`、`Placebo`、`Control`）的数值时，必须回查源数据表该行，严禁把 `High-dose` 或阳性亚组的数值、百分比或 `p` 值挂到另一组。
3. **误差棒与有效数字守恒**：明确区分 `SD`、`SEM`、`IQR` 与 `95% CI`，必须与源表表头及图注完全一致。
4. **阴性结果与未达显著趋势必须如实报告**：若源表包含 `p >= 0.05` 或 `FDR >= 0.05` 的组别/指标，必须在正文如实报告方向与精确 `p` 值（如“呈上升趋势但未达统计学显著，p = 0.142”），严禁隐瞒或升级为显著/因果。

## 二、Discussion（讨论段）：四拍综合架构（禁复述流水账）

针对社区痛点（分开写易重复、只堆 p 值不讲含义），Discussion 采用四拍综合结构：

1. **第一拍｜主发现直答科学问题**：用 1–2 句综合概括核心实证发现如何回应开篇研究问题，**不机械照抄 Results 全量数字**。
2. **第二拍｜与既有文献结构化对照**：区分与对照文献的**一致处**与**分歧处**，并从研究设计、样本人群/物种、剂量/检测方法、统计模型等**具体方法差异**解释为何结论不同，避免只堆引文不讲关系。
3. **第三拍｜有界机制讨论（明标推测）**：对尚未被本实验直接验证的通路或机制，必须使用克制限定词（`may reflect`、`is consistent with a hypothesis that`、`可能反映`），严禁将观察性关联写成已证实因果。
4. **第四拍｜具象局限性（四层面落点）**：必须落到具体的**方法设计、样本规模/代表性、测量精度或统计检验/多重比较**层面，并指出该局限对结论外推范围的实际约束，拒绝空洞套话。

## 三、反防御性措辞与去 AI 味平衡

- 依据「发布会原则」，在主结果句中清除“遗憾的是”“仅是初步尝试”等自我贬损套话；真正的样本量、未显著组与设计局限放在对应观测句和专门 Limitations 段客观交代，做到**不夸大、不自贬、全溯源**。
